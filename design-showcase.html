规范章节页面位置修改方式
§1 配色色块 + hex 值"bg_root 改成 #XXXX" → 改 CSS 变量 + theme.py TOKENS
§2.2 字号逐级渲染文字"SIZE_BODY 改成 15px" → 改规范文档 + theme.py + CSS
§2.3 字重字重用法表格"卡片标题用 600" → 改 §2.3 表格 + 相应组件
§3 间距等比色条"卡片间距 20px" → 不在网格，建议 16 或 24
§4 圆角三级方块"卡片圆角 10px" → 提醒必须统一，建议 8 或 12
§5 按钮四层×四态矩阵"次按钮 hover 背景 6%" → 改 §5 表格 + CSS
§6 渐变径向光晕演示"空状态渐变更明显" → 调不透明度上限
§7 阴影四级卡片"卡片阴影太重" → 改 elevation 1 值
§9 动效按钮悬停过渡"按钮过渡 200ms" → 改 CSS transition
