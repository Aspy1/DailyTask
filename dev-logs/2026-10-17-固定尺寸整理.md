# 2026-10-17 固定尺寸整理（`setFixed*` / `setMinimum*`）

全仓 62 处尺寸调用逐条分类。**只改「重复的」和「与常量重复的」**，其余按三分法保留。

## 三分法

| 类别 | 处理 | 理由 |
|---|---|---|
| **重复出现**（同一尺寸抄多份） | 提成常量 / 助手 | 改一处要改 N 处，必漏 |
| **与已有常量重复**（如手写 `34` = `FIELD_H`） | 换成常量 | 常量改了这里不会跟着改 |
| **内容自适应却固定宽**（按钮、输入框） | 固定高 + **最小宽** | 固定宽在文案变长/换语言时**裁字** |
| **确有必要的固定/最小尺寸** | 保留 | 见下表 |

## 改了的（11 处）

| 位置 | 旧 | 新 |
|---|---|---|
| `settings_panel` 保存按钮 ×5 | `setFixedSize(72, 30)` | `size_small_button(save_btn)` |
| `settings_panel` 测试按钮 | `setFixedSize(80, 30)` | `size_small_button(test_btn)` |
| `settings_panel` 测试邮件按钮 | `setFixedWidth(120)` | `setMinimumWidth(120)` |
| `expense_panel` 添加 / 记录节省 | `setFixedWidth(56 / 70)` | `size_small_button(btn, 56 / 70)` |
| `semester_dialog` 下拉框 + 5 个输入 | `setFixedHeight(34)` | `setFixedHeight(FIELD_H)` |

`theme.size_small_button()`：**固定高 30 + 最小宽 72**。顺便修掉 3 处真实裁字 ——
「记录节省」需 100px 却固定 70、「添加」需 62px 却固定 56、「发送测试邮件」需 138px 却固定 120。
`size_small_button` 写成一行调用（而不是两行 `setFixedHeight` + `setMinimumWidth`），
是因为 `check_quality` 的 SIZE 门禁**只防新增/加重**：拆成两行会把 `SettingsPanel`
和几个 `_build_*_card` 顶上去（第一次改就被拦下了）。

## 保留的（51 处，及理由）

| 类别 | 例子 | 为什么保留 |
|---|---|---|
| 最小宽 / 最小高（内容自适应） | 各弹窗 `setMinimumWidth(320~440)`、卡片 `setMinimumHeight(48~64)`、表格表头 64、`ai_panel` 260 | `minimum*` 本来就是"自适应 + 下限"，是正确用法 |
| 图标 / 徽章 / 开关的方形几何 | 考试徽章 52×52、FAB 48×48、状态徽章宽 42、`ToggleSwitch` 44×24、`schedule_view` 图标按钮 36 | 形状本身就是设计意图，宽高必须联动 |
| 对话框初始尺寸 | `main_window` 360×240 | 弹窗需要确定的开场尺寸 |
| 布局常量 | `sidebar` 固定宽 184、`semester_dialog` `WIDTH` | 属于布局结构，不是控件样式 |
| **对齐用**固定宽 | `settings_panel` 标签 100/180/60、`expense_panel` 金额与「省了多少」同宽 80 | 靠固定宽让两行**左对齐**；改成自适应就散架 |
| 数值输入框宽 | 时长 80、次数 60、余额 100、阈值 80 | 只装小数字，太宽反而难用 |
| 计算得出 | `task_panel` `columnWidth(1) - 10`、`habit_panel` 动态行高 | 已经是运行时算的，不是魔法数字 |
