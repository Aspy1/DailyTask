## 发现的跨模块 Bug

| Bug | 影响范围 | 修复 |
|---|---|---|
| run_in_process 缺 argparse 默认值 | AI 全线命令静默失败 | 22 个参数 pre-fill |
| _on_data_changed 遗漏 ai_action | task/expense/habit 面板不刷新 | 统一 is_ai 检查 |
| parse_date 不认"这周五" | AI 日期解析失败 | 正则 + 中文时间 |
| send_digest SMTP 未 catch | GitHub Actions exit 1 | try/except |
| categories property fallback=["其他"] | filter 只显示一个分类 | 引用 DEFAULT_INVENTORY |

## 教训
- `content.replace()` 批量替换极其危险——很容易把不该替换的也换了（_breadcrumb.hide → _update_breadcrumb 递归）
- 手动 parser 必须同步 argparse defaults（22 个可选参数）
- `args.xxx or default` 不防 AttributeError——Python 先求值左侧
