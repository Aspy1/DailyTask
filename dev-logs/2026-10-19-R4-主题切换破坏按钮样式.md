# 2026-10-19 R4：主题切换破坏按钮样式与伪状态选择器

## 起因

`PLAN.md` P22 批次二第一条（`REVIEW.md` R4）。两个**互相独立**的病灶：

### 病灶 1：`remap_colors` 的正则扫整段 QSS

```python
_DECL_RE = re.compile(r"(?P<prop>[a-zA-Z-]+)\s*:\s*(?P<value>[^;{}]+)")
return _DECL_RE.sub(_sub, qss)      # ✗ 整段替换
```

`QPushButton:hover` 里的 `hover` 被当成**属性名**匹配 ✗ → 输出 `QPushButton: hover`
（冒号后多一个空格）→ **伪状态选择器全被改坏** ✗（hover / pressed / disabled 失效）。

### 病灶 2：全局换样式把"原始样式"覆盖掉了

`RoundedButton._absorb_qss()` 会把 QSS 里的背景/描边"搬到自己身上"，并把
`setStyleSheet()` 换成**剥掉背景**的那份 ✗。而 `changeEvent` 里：

```python
if event.type() == QEvent.Type.StyleChange and not self._absorbing:
    self._original_qss = self.styleSheet()      # ✗ 这已经是剥过的那份
```

应用换主题走的是 `app.setStyleSheet(theme.switch_theme('dark'))` —— **全局**变化同样发
StyleChange ✗，于是原始样式被自己的"清理版"覆盖 → 自绘底色塌成透明
（实测：四个背景状态变成一个 alpha=0 的 normal，发送按钮只剩白字 ✗）。

> 第一次显示时的状态解析上一轮已经修好 ✓；这条是**真实入口**（`app.setStyleSheet`）上的问题。

## 改法

| 病灶 | 改法 |
|---|---|
| 1 | 只替换**花括号里**的声明：`_BLOCK_RE` 切出声明块再逐条替换，**选择器原样保留** ✓；整段没有花括号时（部件级 `setStyleSheet("color: …")`）仍按裸声明处理 ✓ |
| 2 | 记住"我们自己最后写回去的那份"（`_applied_qss`）✓ —— `changeEvent` 里只有当 `styleSheet()` **不等于**它时，才认为"调用方重新给了样式"并采纳为新原始样式；相等 = 全局变化 → **原始样式不动**，只作废吸收缓存 ✓ |
