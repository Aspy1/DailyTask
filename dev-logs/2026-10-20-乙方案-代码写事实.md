# 2026-10-20 乙方案：代码写事实、模型只补说明

用户 2026-10-20 拍板：回复改成**事实由代码写、模型只解释**（乙），并定「未核对」按**丙**显示
（只在同一次里有写命令时才显示）。

## 起因（一句话）

评估集实测：模型**一条命令都没发**却回复"已将羽绒服的位置改为家"，而用户**看不到任何警示** ——
根子是"**模型的话仍是主报告**"，代码只能事后补告警 ★。

## 做了什么

1. **账本 → 事实行**（`src/services/ai_ledger.py`）：
   - `Goal` 增加 `label`（对象名：布洛芬 / 羽绒服 / 计划标题）；
   - `VERB` 把操作映射成中文动词（记入 / 扣减 / 移动 / 标记完成 …）；
   - `fact_line()` 生成一行事实（动词 + 对象 + **证据**：`余量 24 → 23`），
     状态用**中文**表达，**不用 ✓/✗ 符号**（用户明确不要）；
   - `render_facts()` 负责乙的排版：**事实块在前、模型的话作为【说明】在后**；
     没有写命令 → 只有模型的话（丙 ✓）。
2. **对象名在执行前取**（`ai_verify.label_of()`）—— 像 `delete_item` 执行完对象就没了。
3. **worker 收尾**（`AIWorker._report()`）改成调用 `render_facts()`；
   账本仍走独立信号（§2.4），进日志、供下一次"继续"用。
4. **提示词**：把"完成后用一行总结操作结果"改成"用一句**补充说明**，
   **不要**复述『已记录 / 已完成 / 已改为』——实际执行结果由程序单独显示"。
5. **异常不再被吞**：`run()` 的 `except` 加 `logger.exception`（原来只有一句 `str(e)`，
   排查时没有 traceback —— 这次就是靠它才定位到 `@staticmethod` 残留的 bug）。

```
【说明】
  过季收好，来年要寄回学校时说一声。
```
