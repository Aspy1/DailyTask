# 2026-10-18 用户看渲染截图提的 5 条 UI 反馈

用户打开 `scripts/ui_render.py` 出的图逐张挑问题。逐条处置：

## 1. 习惯卡徽章三个大小不一致（`dark-daily.png`）

**现象**：三张卡的「今日未打卡」徽章大小不一 —— 标题换两行的那张卡更高，徽章跟着被**拉伸**。

**修法**：`row1.addWidget(tag, 0, Qt.AlignmentFlag.AlignTop)` —— 钉住对齐方式，徽章就用
自己的 `sizeHint`，不再跟着卡片高度变 ✓。

> 用户原话提到的是「完成打卡」大小不一致，但圈的是徽章；「完成打卡」按钮三个本来就一样大。
> 徽章改完三个一致（**没改文案**：`今日未打卡` 信息量更大，尺寸问题靠对齐就解决了）。

## 2. 考试倒计时应是**圆**（`dark-exams.png`）

**根因**：徽章已经是 `setFixedSize(52, 52)` 正方形，但圆角用了 `RADIUS['radius_pill']`（**999**）
—— Qt 对超大圆角处理不对，画出来是**圆角方块**（只有 `>15 天` 那一档写死了 `26px` 才是圆）。

**修法**：新增 `controls.circle_badge = 52`，圆角取 `CIRCLE_BADGE // 2` ✓
（**别用 `radius_pill`**，注释里写明原因）。同时把 5 个分支收敛成一组变量，顺手少写 4 个 `font-size` 字面量。

## 3. AI 回复行间距过大 + 下面那句"提示"看不懂（`dark-narrow-expenses-ai.png`）

**行距**：`_md_to_html` 用 `<ul>/<li>` —— Qt 给列表项加的**块间距很大**。
改成 `•` + `<br>` 直接拼，并**折叠空行** ✓。

**那句"提示"是假的** ⚠：`使用 lookup_item --name 维生素片 查询物品。` 是我在
`scripts/ui_render.py` 里**编的测试数据**，不是产品行为。用户被它误导了 —— 已把 fixture
换成像真的回复。**教训：渲染 fixture 也要写得像真的，否则会把假象当 bug 报上来。**

## 4. 标签弹窗行距大、没有区分底色（`dialog-tags.png`）

量了一下（探针脚本）：应用级 `QListWidget::item { padding: 8px 12px }` 让基础行高 = **48px**。
我第一版改法**没看出来**，因为浅色下 `bg_elevated` 与 `bg_input` **同色** ✗。

**修法**：新增 `item_bg` 令牌（浅 `rgba(0,0,0,0.04)` / 深 `rgba(255,255,255,0.06)` ——
两模式都看得见），`padding: 2px 10px; margin: 2px 0` → 行高 48 → 约 40 ✓。

> 记一笔：`bg_elevated` **不能**用来做"列表项淡底" —— 浅色主题下它和 `bg_input` 都是
> `#FFFFFF`，改完等于没改。
