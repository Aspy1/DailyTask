# 2026-10-18 C 类第 5 项续：常备量（剩 1/4 提醒）

`PLAN.md` P20 的"常备药"给了两条路：
1. 新增 `stock_target`（常备量）
2. 或约定 `min_quantity = 常备量 / 4` 复用现有阈值

**选了 1** —— 因为"**低于多少提醒**"和"**应该常备多少**"本来就是两件事 ✗：
用户说"常备 6 盒"时，他心里是"我该有 6 盒"，而不是"低于 1.5 盒提醒我"。
混用还有个实际麻烦：**用户改常备量时得自己算 1/4** ✗。

## 规则

```python
target = item.get("stock_target") or 0
if target > 0:
    return "不足" if left * 4 <= int(target) else "充足"     # 剩 ≤ 常备量的 1/4
```

- 用**精确余量**（`remaining_doses`）比 ✓ —— 和 `min_doses` 同一口径（一盒用剩几片时盒数是 0 ✗）
- **设了常备量就按它算** ✓ —— 不让两个阈值互相打架（`min_quantity` 退回不用 ✓）
- 空了还是"需购"（不是"不足" ✓ —— 两者含义不同 ✓）
