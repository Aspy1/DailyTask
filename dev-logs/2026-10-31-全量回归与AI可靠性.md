## 目标

模拟真实用户从"打开软件 → 每个面板 → 核心操作 → AI 助手"走一遍；
用**离线脚本化模型**验证助手"说了 vs 做了"的一致性。

  - 最后用真实 `main.py` 子进程启动一次（离屏 + 沙箱），确认首屏不崩

## 走查抓到的问题

### 1. `_version` 缺失 → 第一次 UI 保存被误判成"外部改动"（严重）

- `scripts/actions.py` 写 JSON 时**不写 `_version`**；
- `BaseJsonModel.load()` 读盘后在**内存**里补 `_version=1`，然后才计算磁盘指纹
  → 内存指纹永远 ≠ 磁盘指纹；
- 结果：AI/CLI 刚写过的文件，用户在界面上做第一次修改时 `save()` 被拒绝，
  改动只落到 `backup/save_conflict/`，磁盘不变（走查日志里 4 个文件同时出现）。

修复：
- `load()` 在补默认值**之前**计算磁盘指纹；
- `actions_core.save()` 统一写 `_version`（值来自各模型 `DEFAULT_*`，唯一真值）；
- `flush_on_exit()` 比较时对旧文件缺失的 `_version` 做同口径归一；
- 新增 3 条回归测试（actions 写版本 / 模型随后可保存 / 旧文件退出不产生假冲突）。

### 2. `ToggleSwitch` 没有 `clicked` → 真实应用启动即崩

- 上一轮把设置页插件开关从 `toggled` 改成 `clicked`（按 QCheckBox 的 R-008 惯例），
  但 `ToggleSwitch` 是自绘控件，只暴露 `toggled`，且 `setChecked()` 不发信号；
- 走查的沙箱没有插件 → 没暴露；真实 `main.py`（有插件）启动时 `AttributeError`。
- 修复：改回 `toggled`，并在注释里写明"该控件 setChecked 不发信号，不存在回环"。

### 3. 支出事实行没有对象名

- `label_of(add_expense)` 为空 → 事实行只有"记支出：¥18.00"，看不出买了什么；
- 修复：`add_expense` / `add_saving` 用 `--note` 作为对象名。

### 4. 其他

- `QMessageBox` 在离屏走查里会永久阻塞 → 走查脚本统一替换为记录型替身；
- `app.log` 路径随 `LIFE_ASSISTANT_DATA_DIR` 走，沙箱日志不再写进真实 `data/`。

## AI 可靠性：验收面扩大

`services/ai_verify.py` 原先只有 6 个验收器，现在覆盖**全部写命令**：

| 类别 | 验收方式 |
|---|---|
| 作业 | 新增：数量增加 + 标题存在；完成：进入 `archived` 且 `completed` |
| 课程 | 新增/删除：数量与名称；修改：逐个核对显式传的字段（名称/星期/周次/节次/单双周/教师/地点） |
| 考试 / 习惯 | 数量 + 名称/课程日期；打卡后 `completed=True` |
| 日程 | 新增/替换/删除：按标题列表**逐项**比对（能发现"删错了那条"） |
| 记账 / 存钱 | 数量增加 + 金额/日期匹配；删除：id 消失 |
| 财务 | `finance_set` 后逐字段比对 |
| 位置 | `add_location` / `set_locations` 后清单比对 |
| 库存 | 新增/删除/消耗/位置/数量（原有） |

- `tests/test_ai_verify.py` 新增：
  - `test_every_write_command_has_a_verifier`（新增写命令忘记验收器会红）
  - `test_all_write_commands_verify_against_real_data`（每条命令真跑 + 真验收）
  - `test_claiming_ok_without_the_data_is_a_mismatch`（命令说 OK 但数据没变）
