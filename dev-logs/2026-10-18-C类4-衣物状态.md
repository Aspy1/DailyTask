# 2026-10-18 C 类第 4 项：衣物状态（穿了几天 / 该洗了）

用户用例表第 13/22 条：
- 13："毛巾两条 一条蓝色一条黄色 在晾衣架上" + 备注"是否正确初始化提醒清洗的日程表"
- 22："我把衣柜3最里面的蓝色床单换来用了 记得提醒我洗之前的蓝色床单"

## 两个设计选择（都有今天的教训在后面）

1. **不存"穿了几天"计数器** —— 计数器要有人记得每天 +1（漏一天就错，跨天 / 跨设备必错 ✗）。
   存 `worn_since`（从哪天开始穿），天数**每次算** ✓ —— 和 `runs_out_on` 同一个思路。
2. **"该洗了"走「今日提示」，不进物品状态** —— 物品状态那套是"**库存够不够**"
   （充足/不足/需购），跟"该不该洗"是两回事 ✗；混在一起会让"该洗的毛巾"看起来像"缺货" ✗。
   提示骨架上一项（C 类第 3 项）刚搭好，这里就是**加一个规则函数** ✓。

## 字段与命令

| 字段 | 含义 |
|---|---|
| `worn_since` | 从哪天开始穿 / 用（**日期**，不是计数器） |
| `wash_after_days` | 穿够几天算该洗（**阈值可配**，跟着"穿够几天就洗"走） |
| `needs_wash` | 显式标记（"我把这条换来用了" → 直接就该洗） |

命令：`--worn-days N`（**代码算起始日**）/ `--needs-wash yes|no` / `--wash-after N`。

判定在 `inventory.needs_wash_now()`：**显式标了 → 该洗**，或 **穿了 ≥ 阈值 → 该洗** ✓。
