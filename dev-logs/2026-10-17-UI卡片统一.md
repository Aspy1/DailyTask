## 变更清单（本轮）

1. **`sub` 变体**：左侧 4px 色条（`BAR_W = SPACING["spacing_xs"]`，不写像素）+ 只右两角圆。
   左两角改方靠 `QPainterPath` 的**并集**（`WindingFill` + `addRect`）——
   默认的奇偶填充会把重叠区**挖空**。
2. **层级缩进**从 QSS `margin-left` 改成外层**容器控件**的左边距。
   老写法其实无效（QSS `margin-left` 只改控件内容区，缩不了控件本身）；
   且必须用容器**控件**而不是嵌套 layout —— `_refresh()` 靠 `item.widget()` 清卡，
   嵌套 layout 的 `item.widget()` 是 `None` → 旧卡不删、残留在屏幕上。
3. **派生色清零**（本批）：`c["red"] + "10"` / `c["orange"] + "10"` → `red_tint` / `orange_tint`；
   考试卡的橙档改用 `orange_tint_weak`（0.03）以保持紧迫度梯度不倒挂。
4. **`Card` 支持可点击卡**：`bg=` / `hover_bg=` 传**令牌名**，`paintEvent` 里现取 → 切主题自动跟随。
5. **`qcolor()` 修 8 位 hex 语义**：QSS 按 CSS 的 `#RRGGBBAA` 读，Qt 的 `QColor` 按
   `#AARRGGBB` 读 —— 同一串颜色两种含义（实测 `#d6454512` → `rgba(69,69,18,214)`）。
   新增令牌一律用无歧义的 `rgba(...)`。
