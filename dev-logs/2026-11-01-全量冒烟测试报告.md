## 2. 用户报障路径复现

### 2.1 天气详情「未来3天」只显示日期

**复现**：打开天气详情，`_forecast_rows` 中日期标签有文本，天气/温度标签文本也存在，
但屏幕上不可见。

**根因**：`_build_forecast_rows()` 每行建了 `QHBoxLayout`，却只执行
`self._layout.insertWidget(3 + i, row_layout.itemAt(0).widget())` —— 只把**日期标签**
插进主布局；`text/rain/temp` 三个标签没有父控件/布局，永远不会显示。

**修复**：每行包一个 `QWidget` 容器，插入整行；并增加无数据空态。

**回归**：`tests/test_weather_dialog.py::test_forecast_rows_show_weather_text_and_temperature`
断言日期、天气文字、温度都非空且 `isVisible()`。截图 `dialog-weather.png` 已确认
三行完整显示（11-02 多云 7–15°C、11-03 晴 8–17°C、11-04 小雨 9–14°C / 2.4mm）。

### 2.2 刷新崩溃 `QThread: Destroyed while thread is still running`

**复现**：天气刷新启动 `WeatherWorker` 后关闭应用/再次刷新，控制台打印该警告，偶发崩溃。

**根因**：`WeatherWorker` / `_ApiWorker` / `_GitWorker` 都继承 `QThread`，并声明了
`finished = Signal(...)`。同名信号**遮蔽**基类 `QThread.finished`，所以
`worker.finished.connect(worker.deleteLater)` 实际连到 `run()` 内刚发出的结果信号；
此时线程还在收尾，QThread 对象被删 → Qt 报 "Destroyed while running"。

**修复**：结果信号改名 `result` / `failed` / `done`；对象回收统一连
**`QThread.finished`**；`WeatherService.shutdown()` 停定时器并 `wait()`；
`MainWindow.shutdown()` 在 `App.quit` / 重启前调用。

**回归**：`test_qthread_subclasses_do_not_shadow_finished`（三个类结构断言）。

### 2.3 未配置天气时刷新按钮永远停在 `...`

**根因**：`WeatherService.refresh()` 在没有 Host/Key 时直接 `return`，不发任何信号，
弹窗的 `_update_content()` 永远不会恢复按钮。

**修复**：`refresh()` 返回 bool 并 `error_occurred.emit`；弹窗连接错误信号，
恢复按钮并显示原因；无预报时显示"暂无预报数据"。
