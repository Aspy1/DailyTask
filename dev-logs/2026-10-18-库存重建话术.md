# 库存重建话术（2026-10-18）

> 配合新口径：**说了位置就照抄，没说位置就是「学校」**。
> 重建前**先重启应用**（新命令、新提示词都是这次改的代码，正在跑的应用还是旧的）。

## 一、只需要记住一件事

**位置就是归属。** 你说了格位就用格位；没说就自动记成「学校」；
"寄回家 / 收起来过季" 记成「家」；"寄回来" 记成「学校」。

位置词表当前 14 个：你那 12 个格位 + 「学校」+「家」。
清单里没有的格位**直接说**（例如"放书房抽屉"），AI 会自己加进清单并在回执里写"新增位置"。

## 二、逐条说（一次说 3–5 条，别一次全塞）

| 你的情况 | 照这样跟 AI 说 |
|---|---|
| 有具体格位 | `抽纸 3 提，放阳台储物柜` |
| 在学校但不用指明格位 | `洗衣液 1 瓶` ← 位置自动是「学校」 |
| 要补货提醒 | `布洛芬 1 盒 24 片，放药箱；剩不到 5 片提醒我买` |
| 同类不同特征 | `两条充电线，一条 Type-C 一条 Lightning，都在右侧抽屉` |
| 虚拟会员 | `QQ音乐会员，年费` ← 位置留空 |
| 寄回家 | `羽绒服 2 件，寄回家了` |
| 拿回来 | `把羽绒服拿回来，放衣柜左2` |
| 消耗 | `洗手液用掉一瓶` |
| 挪位置 | `创可贴挪到车上急救包` |

## 三、它只查不写时，回一句

模型有时会停在"先查后加"的确认环节（只 `lookup_item`、不 `add_item`）。
这时回一句：**"对，库存里没有，直接新建"**，它就写了。

（这是探针里唯一还没治好的毛病，与归属无关。）

## 四、收尾核对

- `我都有什么` —— 列全部
- `哪些东西该补货了` —— 只列学校那侧（家里的不参与）
- `书架3 上都放了什么` —— 按位置筛
- `我有哪些虚拟会员` —— 按分类筛
- `寄回家的那些还在吗` —— 找「家」那批

## 五、安全网

- 清空前的 11 条旧数据：备份在 `%TEMP%\inventory_backup_before_reset\`，
  而且**在 git 历史里**（`git log -- data/inventory.json`），随时能取回。
- 每次写入前 `actions.py` 会自动备份到 `data/backup/actions/`；
  要回滚用 `restore --name inventory.json --yes`。
