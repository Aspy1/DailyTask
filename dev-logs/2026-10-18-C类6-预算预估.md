# 2026-10-18 C 类第 6 项：预算预估

用户用例表第 16 条备注："新功能：预算预估 涉及现有的分期付款 自动续费 要补货的东西
以及根据之前几个月预估的日常支出"。

## 核心原则：**能算的算，算不出的列出来，不硬编数字**

| 用户提的 | 数据里有没有 | 处理 |
|---|---|---|
| 日常支出 | ✓ 支出记录 | 按**近 90 天**日均 × 本月剩余天数（本月头几天样本太少，单看本月会飘 ✗） |
| 自动续费 | 只有到期日、**没有金额** ✗ | **列出"即将扣费"**（名字 + 日期），不折成钱 |
| 要补货的 | 库存**没有价格** ✗ | **列件数**，不折成钱 |
| 分期付款 | 模型里**根本没有**这个字段 ✗ | 不假装算得出来 |

> 这条比"估个数字"更重要：**硬编一个金额，用户会当真** ✗。

## 纯计算，不存状态
`forecast(records, budget, items, today)` 是**纯函数** ✓ —— 存下来会过期、还要同步 ✗（和会员到期日
那套不同：那是**事实**，这是**推算**）。

```
projected = 本月已花 + 近 90 天日均 × 本月剩余天数（含今天，保守）
over      = 设了预算 且 projected > 预算      ← 没设预算不说超支（0 不是"预算 0 元"）
```
