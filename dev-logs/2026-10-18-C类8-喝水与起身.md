## 关键决定：**不另开定时器**，复用已有的每分钟 tick

P20 自己就点出了两条现成情况：
1. 托盘 `showMessage` 在 Win10+ **本来就是原生 toast** ✓ → 不用另接 API，**主要是换节拍**
2. 现有提醒是**每天一次**的日检（`ReminderService` 每 60 秒 tick 一次）

所以"每半小时"**不需要**再挂一个 30 分钟定时器 ✗ —— 那会有两个节拍互相错位、还要管暂停/恢复 ✗。
改成：**在已有的 tick 里做判定** ✓

```python
def water_reminder_due(now, last_sent, quiet) -> bool:
    if _in_quiet(now, quiet): return False          # 免打扰（默认 23:00–07:00，跨零点 ✓）
    return last_sent is None or (now - last_sent) >= timedelta(minutes=WATER_INTERVAL_MIN)
```

P20 点名的三件事都照顾到了：
- **免打扰时段** ✓（`General/quiet_start` / `quiet_end`，跨零点 ✓，可覆盖 ✓）
- **只在开机时段跑** ✓（服务在跑 = 开机 ✓）
- **总提醒开关** ✓（`_notify` 统一把关 ✓，另有 `General/water_reminder` 单独开关）
