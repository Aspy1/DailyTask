# 2026-10-18 AI 可靠性：从"模型说了算"到"代码说了算"

今天 AI 侧的主线。起因是 α 测试发现**模型会"说了没做"**，一路挖到根，并参照
`Agent Reliability Engineering Design Guide` 把判定权从提示词/模型搬到代码。

## 一、四层病根（**同一族**，逐个击破）

| # | 病根 | 现象（实测） | 修法 |
|---|---|---|---|
| ① | **模型"说了没做"**（叙述代替命令） | 回复"已记录：毛巾 2 条…"但**一条命令都没发** | 提示词"先发命令再说话" + 护栏追问 |
| ② | **"记账动作"被当成"用户要的效果"** | bonsai 发了 17 条 `add_location`（全 OK）→ 判定为"写过"，实际**物品只落 6 件** | 按**命令名**区分：`add_location` / `set_locations` 是记账类，**不算**用户可见效果 |
| ③ | **判定挂在模型的措辞上** | 只对"声称已记录"报警 → 模型改口"无需写入"就静默了 ✗ | 改成**命令自己的结果**（`OK` / `ERROR`）才算数 |
| ④ | **部分完成当完整呈现** | deepseek 整批漏掉 19 件（两条最长提示词），**没有任何提示** ✗ | 量化上报 + 被轮次/时限切断也要说 |

**效果**：同一份代码、同一个弱模型（bonsai），把 ② 修掉后落库从 **6 件 → 47 件** ✓。

## 二、现在的判定链（全部在代码里，不看模型怎么说）

```
每轮：执行命令 → 逐条看返回
  · 写命令返回 OK      → ok_count += 1     （真的落了库）
  · 写命令返回 ERROR   → write_failures   （要如实告知）
  · 只有记账/查询命令  → 不算效果
  · 同一批命令重复且无效果 → repeat_nudge（第 2 次告知 / 第 3 次收束）

收尾（`_finish`）：
  · 有失败 → "⚠ N/M 条写命令没有生效：<逐条列出>"
  · 被轮次/时限切断 → "⚠ 可能没记全 —— 执行 N 条、写命令成功 K 条；回"继续"我接着记"
  · 一条命令都没发却说"已完成" → "⚠ 数据没有任何改动"
```

## 三、论文里照抄的东西（`Agent Reliability Engineering Design Guide`）

| 出处 | 抄了什么 |
|---|---|
| §2.3 "the agent is also the reporter" | **模型的自我描述不是测量** → 汇报权归代码 |
| §4.3 进度谓词 | 定义里**排除模型的任何自述**（"输出变长"不是进度） |
| §4.4 分级响应 | 告知 → 收束 → 收尾（不是直接 abort） |
| §6.3 "enforce at the boundary" | **提示词不是安全机制** → 强制点在 `actions.py`（重复护栏）+ 收尾判定 |
| §9.3 部分结果 | **量化覆盖**（"1/3 没生效"），不是散文（"有些失败"） |
| §13.4 护栏桩测试 | 用桩（不经过模型）直接测护栏 |
| §3.3 双预算 | 轮次（5）+ **墙钟（90s）** 都要有 |

**§14 的反模式表**可直接当自查清单；我们对照后剩下的隐患见下。

## 四、设计取舍（为什么没做某些事）

1. **不做持久化"副作用台账"**（§12.2）—— 论文要求它活在对话之外。我们**天然满足**：
   副作用落在 `inventory.json` / `daily_logs.json` ✓，而系统提示词**每次请求都从数据重建** ✓
   → 模型看到的就是"世界现在什么样" ✓，不需要一份单独的台账。
2. **对话压缩（`_auto_compress`，只留 16 条）的隐患被两道挡住** ✓：
   ① 提示词从数据重建（§10.6 的核心风险被规避）；② `add_item` 有**同名同位置硬护栏**（拒绝重复）。
3. **不换模型解决问题** —— 设计成立后，模型强弱只影响"一次能办成多少"，**不影响"用户会不会被骗"** ✓。

## 六、新增守卫（`tests/test_ai_worker_retry.py`）

- 空回复 / 截断 / 声称写了却没命令 / 说"无需写入"却一条没执行 → 都要续跑
- 纯查询**不**误报
- **重复阶梯**：第 2 次告知、第 3 次收束、有效果就不干预（桩测试，§13.4）
- **量化上报**：`1/3 条没生效`、被切断要说"可能没记全"（桩测试）
- 记账类命令不算效果（`add_location` 不触发"写过"）
