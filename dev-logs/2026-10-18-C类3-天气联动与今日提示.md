# 2026-10-18 C 类第 3 项：天气联动 + 「今日提示」骨架

用户用例表第 20 条（"秋衣秋裤在衣柜2外面 天气冷了就提醒我换"）点的是**天气驱动提醒**。
这一项顺带把我在设计里提过的 **B 类「今日提示」骨架**搭起来了 —— 后面第 7 项（出门提醒）
就是往里加函数。

## 设计：一张容器 + 一组规则函数

天气联动、出门提醒本质是同一件事：**"从已有数据推出来的、今天该提醒你做的事"**。
所以不做成三套提醒框，而是：

```
规则（纯代码，不经过模型）        产出                消费者
  天气 → 带伞 / 加衣 / 防暑      ─→ 「今日提示」条 ─→ 日程界面（每条可点掉）
```

两条约束（都来自今天的教训）：
1. **不让模型判断**该不该带伞 —— 它不可靠 ✗；这类建议由**规则**产生（代码说了算）✓
2. 提示是**视图状态**：点掉只影响今天这一次显示，**不写进数据文件** ✓

`ScheduleView` 类贴着 753 行基线，塞不下提示条 ✗。处置：**把"归入时段"那族搬出类** ——
