# 2026-11-03 考试写入与验收归一化口径不一致（ISSUE-0006）

## 症状

一次请求里 3 条 `记考试` 全部返回 `OK add_exam ...`，验收却全部 `mismatch`：

```
OK add_exam e_001 | 数据挖掘 | 2026-11-20
verify: mismatch —— 考试列表里找不到「数据挖掘」
```

最终向用户汇报"3/6 条写命令没有生效或没达到预期"—— 与事实相反（数据已写入）。

## 证据（真实日志参数）

`data/ai_actions.jsonl` 保留了当时的完整命令与验收结论（节选）：

```json
{"kind":"action","command":"... add_exam --course \"数据挖掘\" --date \"2026-11-20T16:00\" ...",
 "status":"OK add_exam e_001 | 数据挖掘 | 2026-11-20","before":{"count":0},"after":{"count":1}}
{"kind":"verify","state":"mismatch","detail":"考试列表里找不到「数据挖掘」","checked":2,"total":3}
```

关键点：`--date` 传的是 **`2026-11-20T16:00`**（带时间），落盘是 **`2026-11-20`**。
`before/after` 的 count 也证明记录确实新增了一条。

## 根因

写入路径与验收路径用了两套口径：

| 路径 | 代码 | 做法 |
|---|---|---|
| 写入 | `scripts/actions.py::cmd_add_exam` | `match_course(course)` 归一化课程名 + `parse_date(args.date)` 归一化日期后才落盘 |
| 验收 | `src/services/ai_verify.py::_check_add_exam` | 直接拿命令**原始参数** `args["course"]` / `args["date"]` 与落盘字段精确比较 |

于是 `2026-11-20T16:00` != `2026-11-20`、课程简称（如 `语音`）!= 课程表全名
（`语音信息处理`）→ 已写入也判"找不到"。

补充确认：**纯中文日期到不了 handler**。`--date` 的参数规格是严格 `YYYY-MM-DD`
（`actions_specs.py` 的 `"date": ("date",)` → `_iso_date`），中文日期在校验层就被
`ERROR --date 必须是 YYYY-MM-DD 的有效日期` 拒绝；因此可真复现的"非 ISO 日期"形态是
日志里的**带时间字符串**，这也是本次的回归用例输入。

## 变更清单

1. `scripts/actions_core.py`
   - 抽出纯函数 `match_course_from(courses, name)`（`match_course` 的实现原样搬入并复用）：
     验收只读快照也能用**同一套**匹配规则，不必调会走 `semester_paths.resolve()`
     （可能建默认学期）的 `match_course`。
2. `src/services/ai_verify.py::_check_add_exam`
   - 验收前先按写入端同一套逻辑归一化：`match_course_from(_courses(data_dir), --course)`
     + `parse_date(--date)`，再与 `course_name` / `exam_date` 比较。
   - `before.count` 的"确实新增一条"判断、`verified` / `mismatch` 语义、提示文案结构不变。
3. `tests/test_ai_verify.py`
   - 新增 5 条 `add_exam` 用例（见下）。
4. `ERRORS.md`：新增 `#060` 与索引行。
5. `MD-files/ARCHITECTURE.md`：可靠性表补一行"验收与写入同一口径"。

未改动：`cmd_add_exam` 写入字段/字段顺序、`exams.json` 结构、考试 UI、参数校验规则。

## 回归测试（`tests/test_ai_verify.py`）

| 用例 | 断言 |
|---|---|
| `test_add_exam_with_a_datetime_is_verified` | 真实日志参数（`--date 2026-11-20T16:00`）→ `verified`；落盘 `exam_date == 2026-11-20` 且记录字段集合不变 |
| `test_add_exam_with_course_short_name_is_verified` | `--course 语音` 对课程 `语音信息处理` → `verified`，落盘 `course_name == 语音信息处理` |
| `test_add_exam_without_a_new_record_is_still_a_mismatch` | 命令说 OK 但没新增 → 仍 `mismatch`（不放宽计数判断） |
| `test_add_exam_with_another_date_is_a_mismatch` | 同名课程、日期不同 → 仍 `mismatch`（日期仍是判据） |
| `test_add_exam_with_a_chinese_date_never_reaches_the_handler` | 中文日期在校验层被拒（`ERROR --date`），验收为 `failed` 而非假通过 |
