# 2026-10-18 令牌收尾 · 状态色成套

第四批遗留清单里的「令牌体系 §3 · 状态成套」。做的是**success / warning / danger 三档同构**，
顺手干掉一处**真实隐患**。

## 起因：三档不同构，而且有手工拼 alpha

| 档 | 文字 | 淡底 | 极淡底 | 实心徽章底 | 描边 |
|---|---|---|---|---|---|
| success（`green`） | ✓ | ✓ | **✗** | **✗** | **✗** |
| warning（`orange`） | ✓ | ✓ | ✓ | ✓ | **✗** |
| danger（`red`） | ✓ | ✓ | ✓ | ✓ | **✗** |

因为**没有描边色**，`schedule_view.py` 的「撤销 / 保存」按钮只能**手工拼 alpha**：

```python
background-color: {c['red']}30;      # ← 色值 + 两位 hex
border: 1px solid {c['red']}60;
```

这正是 **U4 明令禁止**的写法（`dev-logs/2026-10-18-UI审查整改第一批.md`）：Qt 的 QSS 把
8 位十六进制当 **AARRGGBB**，`#B93B3B18` 是透明橄榄色而不是浅红。现在恰好因为令牌是
6 位 hex 才"看起来对"—— **一旦令牌改成 `rgba(...)`，拼出来的字符串直接是坏值**。

## 做法：补齐三档，并让"成套"变成可执行的不变量

### 1. 令牌（`design/tokens.json`，唯一真值）

新增 **12 个**（三档 × 4）：

- `btn_success_fg` / `btn_success_bg` / `btn_success_bg_hover` / `btn_success_border`
- `btn_warning_*` · `btn_danger_*`（同四件）

命名跟着**已有的** `btn_secondary_bg` / `btn_secondary_fg` / `btn_secondary_hover` 走 ——
状态按钮就是次按钮的"带色版"，不另起一套。

再补两个让淡底一族同构：`green_tint_weak`、`green_fill`。

底色/描边直接是**自带透明度的完整值**（`rgba(58,116,77,0.18)` / `0.38`），
调用点直接塞进 QSS，**不需要**在外部拼。

颜色 53 → **67 键 × 浅深两模式**；`color_notes` 同步补齐（67 条）。
`scripts/gen_design_tokens.py` 已重跑，`DESIGN_TOKENS.md` 同步。

### 2. 迁移调用点

`src/ui/widgets/schedule_view.py` 的「撤销」「保存」按钮改用
`btn_danger_*` / `btn_success_*`，删掉拼 alpha 的写法。

### 3. 把不变量写进测试（`tests/test_design_status_tokens.py`，6 条）

- 每档在**浅深两模式**下成员齐全，且每个键都有 `color_notes`
- 三档成员**形状一致**（把色名/档名换成占位符后三组必须完全相同）
- 状态按钮的底色/描边是**完整颜色值**（`rgba(...)` 或 `#RRGGBB`）
- **`src/` 里不许再出现** `{c['red']}30` 这种拼法（正则守卫）

## 验证

**561 passed**（+6）；`ruff` / `check_ui_tokens --strict --check-px` / `check_quality --strict` 全绿。

## 交互状态成套（focus）

焦点描边原来**散着用 `accent`**，而 `ToggleSwitch` 的焦点环用的是 **`accent_text`**
—— 那是个**文字**令牌，语义错位：文字色要满足正文对比度（4.5:1），焦点环是**非文本**
（3:1 即可），两者要求不同。现在统一到新令牌 **`focus_ring`**（每模式取最显眼的强调色变体：
浅色 `#8C5F24`、深色 `#D9AE58`）。

迁移的 7 处：

| 文件 | 位置 |
|---|---|
| `src/ui/styles/theme.py` | `QTextEdit/QPlainTextEdit:focus` · `QLineEdit:focus` · `QComboBox:focus` · 弹窗内 `QLineEdit:focus` |
| `src/ui/components/ai_panel.py` | 输入框 `QTextEdit:focus` |
| `src/ui/widgets/rounded_input.py` | 自绘输入框的聚焦描边 |
| `src/ui/widgets/toggle_switch.py` | 开关的 2px 焦点环 |

守卫（`tests/test_design_focus_tokens.py`，3 条）：`focus_ring` 两模式都有实色 + 有说明；
**`src/` 里任何 `:focus` 行都不许再出现 `accent` / `accent_text`**；开关焦点环必须用该令牌。
