# 2026-10-18 UI 审查整改 · 第四批（第一批切片）

第四批量最大（布局适应 + 弹窗统一 + 令牌体系 + 门禁），这一轮先做**最便宜、最显眼**的三条。

## U9-a · 弹窗英文 OK/Cancel（已修）

**修法**：`init_theme()` 里装 Qt 自带的中文翻译（`PySide6/translations/qt_zh_CN.qm`）。

一次性中文化**所有** Qt 原生字符串 —— 不只 `QDialogButtonBox`（15 处、4 个文件），
还有日历弹层、上下文菜单等 Qt 内部文本。比逐个 `setText` 干净得多。
⚠ 必须留 translator 的引用（`app._qt_translator`），否则被回收后翻译失效（Qt 经典坑）。

## U7 · 开关只有鼠标路径（已修）

`ToggleSwitch` 原来是 `QWidget` + 默认 `NoFocus` → **Tab 到不了、键盘切不了**。现在：

- `StrongFocus` + Space/Enter 可切换 + 可见焦点环（用 `accent_text` 画 2px 圆角环）
- 无障碍名（`setAccessibleName`/`Description`，走 i18n）
- ⚠ 顺带修一条语义 bug：`setChecked()` 是**程序性**赋值，原来**会发** `toggled` ——
  设置面板构造时用它初始化，等于"从数据刷新界面"反过来触发写回（`R-008` 记的那类回环）。
  现在只有用户操作（鼠标/键盘）才发信号。

## U6-a · 习惯卡裁切（已修，且**缩小了文件**）

根因有两层：

1. `_HabitCard` 是 `setFixedHeight(135)` → 长标题/多标签被硬裁；
2. `_FlowGrid` 只用卡片**当前**高度、宽度也从不均分 → 右侧留一大片空白。

**修法**：

| 位置 | 改动 |
|---|---|
| `_HabitCard` | `setMinimumHeight`（不是固定高度）+ 名称换行 + `setToolTip` 给完整内容 |
| 网格 | **列数自适应 + 均分余宽**；行高取 `max(最小高度, sizeHint)` —— 内容撑高不裁切 |
| 抽离 | `_FlowGrid` → `src/ui/widgets/flow_grid.py`（`FlowGrid`，通用件：库存标签也能用） |

**门禁**：`habit_panel.py` 本来 **953 行**（远超 800，存量债），我加几行就"加重"→
把网格抽出去后降到 **909**（净减 44 行），既过门禁也顺手还了一点债。
