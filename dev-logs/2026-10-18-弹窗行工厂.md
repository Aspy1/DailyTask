# 2026-10-18 弹窗行工厂（U9 其余）

第四批遗留清单「U9 其余 · 统一 Dialog/FormRow/Field/ActionRow 工厂」。

## 起因：4 套行 + 2 套按钮行

| 位置 | 形状 |
|---|---|
| `semester_dialog._field_row` | 标签在**左**（固定 88） |
| `inventory_dialogs._labeled_field` | 标签在**上**、输入框在下 |
| `settings_panel._row` | 标签固定 100、**居中** |
| `habit_dialogs` / `exam_panel` / `api_test_dialog` | 裸 `QFormLayout` |
| `schedule_actions._dialog_buttons` | 按钮行（内联 QSS、`padding: 6px 18px`） |
| 各弹窗自写按钮行 | 同上，尺寸/字号各不相同 |

`Q-H9` 的原话就是"并排看就不是一套东西"。而且 `Q-H11` 要求"**主操作在最右**"、
危险操作用 `red_fill` 填充 —— 没有工厂时这些只能靠人工核对。

## 做法

### 1. `dialog_shell.form_row(label, field, label_width=88)`（唯一行工厂）

标签在左、固定宽度，控件占满余下宽度。**标签不写内联样式** —— 由 `dialog_qss()` 的
`QLabel` 规则统一决定（否则又回到"每个弹窗各写一套"）。

### 2. `dialog_shell.action_row(primary_text, on_primary, *, cancel_text, on_cancel, danger)`

顺序**取消在左、主操作在最右**（`Q-H11`）；文案缺省走新加的 i18n 键
`widget.dialog.btn_cancel`；主操作走 `btn_primary_qss()`，`danger=True` 走新的
**`theme.btn_danger_qss()`**（`red_fill` + `fg_on_fill`，Q-H11 要求）。

### 3. 迁移调用点

- `semester_dialog`：删掉 `_field_row`，改用 `form_row`
- `inventory_dialogs._labeled_field`：改成**薄委托**（4 个调用点不动），
  顺带把"标签在上"改成"标签在左"，与其它弹窗对齐
- `schedule_actions`：删掉 `_dialog_buttons`，改用 `action_row`
  （少了一份内联 QSS + `padding: 6px 18px` 的硬编码）

## 顺带修掉一个**看得见**的违规（渲染截图暴露）

用 `scripts/ui_render.py` 出来的 `dialog-exam.png` 一看：按钮行是「**确定　取消**」——
主操作在**左**，违反 `Q-H11`，而且渲染成**扁平文字按钮**、没走主/次按钮工厂。

根因：`QDialogButtonBox` 在 Windows 布局下把 Ok 放在 Cancel 左边，外观也由 Qt 原生样式决定。

于是把**所有 7 处** `QDialogButtonBox` 都换掉（`DialogShell` 自己 + `habit_dialogs` ×4 +
`exam_panel` + `inventory_dialogs` + `api_test_dialog`）→ 现在统一是
**取消（次按钮）在左、确定（主按钮·强调色填充）在最右**。

> 教训：`Q-H11` 这种"看起来只是文案/顺序"的规范，**光读代码看不出来** ——
> 是渲染截图把它逼出来的。

## 收口：`QFormLayout` 三处也迁完

`form_row` 现在**同时收 QWidget 和 QLayout**（"下拉 + 单位文字"这类组合行传 QLayout，
里面套一层透明容器）—— 否则那几行只能退回 `QFormLayout`，统一就漏了。

迁移：`exam_panel`（5 行，改成循环）、`api_test_dialog`（2 组 × 3 行）、
`habit_dialogs`（3 个表单：主表单 4 行 + 消耗数量 1 行 + 附加事项表单 3 行）。
`src/` 里 **`QFormLayout` 归零**，并加了守卫（只认真的在用：`QFormLayout(` 或 import 列表项）。

渲染复核：习惯弹窗（含组合行）标签对齐、组合行正常、按钮行顺序正确 ✓。

## 验证

**572 passed**（+4）；`ruff` / `check_ui_tokens --strict --check-px` / `check_quality --strict` 全绿；
`ui_render.py` 36 张（含 6 张弹窗）全部渲染、退出码 0。

新增 4 条守卫（`tests/test_dialog_rows.py`）：标签在左且不写内联样式 ·
**取消在主操作左边**且回调顺序正确 · 危险操作走 `red_fill` + `fg_on_fill` ·
**不许再造行 helper**（已删除的不许回来；`_labeled_field` 只允许是薄委托，
函数体里必须真的调用工厂）。

## 遗留

- **`QFormLayout` 的三处还没迁移**（`habit_dialogs` / `exam_panel` / `api_test_dialog`）。
  它们本来就是"标签在左"，与工厂一致，所以**视觉上已经是一套**；迁移只是收口，
  优先级低。守卫只防"新增自造实现"，这三处不会被拦。
- `settings_panel._row` 是**面板**行（卡内行，固定 100 居中），不是弹窗行，保持原样。
- 行编辑器 / 日期 / 下拉 / 数字控件仍混用原生与自绘（`QSpinBox` / `QDateEdit` 是原生）。
