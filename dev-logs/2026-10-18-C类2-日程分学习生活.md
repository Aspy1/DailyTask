# 2026-10-18 C 类第 2 项：日程区分「学习 / 生活」

用户用例表第 13 条原话："日程表界面有些拥挤了，加功能区分学习和生活显示"。

## 设计：**规则给默认 + 用户可覆盖 + 顶部筛选**

| 决定 | 为什么 |
|---|---|
| **不按类别分组**，只做筛选 | 日程是按**节次**排的，分组会打乱时间轴 ✗；筛选直接解决"拥挤" ✓ |
| **规则给默认** | 带 `course_name` / 课业类 `type` → 学习；其余 → 生活（大部分自动就对） |
| **用户可覆盖** | 右键菜单「标记为学习 / 生活」→ 存进计划的 `category` 字段，**存过就以存的为准** |
| **不指望模型分类** | 今天已经证明它不可靠 ✗（第 13 条那种"复习英语"它会判错） |
| 筛选是**视图状态** | 和"看哪一边"一样，**不写进数据文件** ✓ |
