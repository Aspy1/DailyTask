# 2026-10-19 R10：`add_item` 的覆盖问题 + 测试覆盖全部字段 + AST 守卫盲区

## 起因

`PLAN.md` P22 批次三（`REVIEW.md` R10）。三件事，都是"上一轮的修法还差一点"：

### 1. `unit` 被硬写，"默认值齐了没有"也没管

```python
item = {..., "unit": "件",                       # ✗ 显式传的 unit 被丢掉
        "status": data.get("status") or self.derive_status(data),      # ✗ 拿原始 data 算
        "remaining_doses": int(data.get("quantity", 1)) * dpu}         # ✗ 同上
```
- 传 `unit="盒"` 进去 → 存下来还是"件"（CLI 那条路没这个问题，因为 `_new_item` 自己拼 dict）；
- `add_item({'name': 'x'})`：余量按原始 `data` 算成 **0** → `_quantity_status` 判 `left <= 0`
  → 直接记成 **"需购"** ✗（刚建的一条就被标成缺货）。

### 2. 行为测试只挑了 C 类字段

`test_inventory_fields.py` 里的样例表只覆盖 8 个 C 类字段 → 其余字段（`unit`、`tags`、
`instances`、`doses_per_unit` …）**没人测** → 上面那个 `unit` 的 bug 就躲在盲区里 ✗。

### 3. AST 守卫有盲区

`test_ui_model_field_contract.py` 里统一要求"**至少两个实参**"才检查 ✗ ——
而 `add_item(data)` 只有**一个**实参 → 所有 `add_item(...)` 调用**从未被检查过** ✗。

## 改法

**1. `add_item` 改成"先默认值、再合并、最后推导"** ✓

```python
"unit": data.get("unit") or "件",          # 显式优先
...
for key, value in data.items():            # 其余可写字段原样带上
    if key in ITEM_FIELDS and key not in item:
        item[key] = value
item["remaining_doses"] = InventoryModel.remaining_doses(item)   # 默认值齐了**再**算余量
item["status"] = data.get("status") or InventoryModel.derive_status(item)   # 再算状态
```

**2. 测试覆盖全部 `ITEM_FIELDS`** ✓

- 手写 `SAMPLES`（22 个字段全有样例值）；
- `test_samples_cover_every_writable_field` 断言 `set(SAMPLES) == set(ITEM_FIELDS)`
  —— **加字段时两边都得动**，否则新字段会漏测 ✓；
- `add_item` / `update_item` 各一条"逐字段都要保住"的测试
  （`update_item` 跳过 `status`：它会被自动推导，是**另一条**已知遗留）。

**3. AST 守卫按方法给"实参下标"** ✓

```python
CHECKED = {"update_item": (1, ITEM_FIELDS), "add_item": (0, ITEM_FIELDS),
           "update_exam": (1, EXAM_FIELDS), "add_exam": (0, EXAM_FIELDS)}
```
现在 `add_item` / `add_exam` 也进扫描了 ✓（本次扫下来 `src/ui` 里没有字面量 dict 的
`add_item` 调用，两个 `add_exam` / `update_exam` 传的是变量 —— 守卫**跳过不硬猜** ✓）。

## 教训

**"修了一半"最危险** ✗ —— R2 把"读取端要统一"修了，但 `add_item` 里**同一件事的写入端**
还留着两处旧写法；而测试的样例表只挑了新加的字段，于是旧字段的坑**没有一条测试站在它旁边** ✓。
配套动作：**样例表要与清单同步**（用一条断言钉住），这样下次加字段时"没测到"会立刻暴露。
