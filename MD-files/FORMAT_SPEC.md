# ATF 格式规范

> AllTheFiles 项目的文档格式标准。atf-writer skill 以此为准。

---

## 一、全局文件格式（AllTheFiles.md）

### 必需章节

```markdown
# AllTheFiles.md

> **R-000** 只读规则

简介段落

> 最后更新：YYYY-MM-DD

> ⚠️ **禁止清单**：见 [项目级禁止清单](#项目级禁止清单)

---

## 目录
  ### 项目级章节
  | 章节 | 内容 |
  ### 文件详情（每个文件通用格式）
  （模板）

---

## 索引                       ← 文件树，已完成的加 ✓，可点击的加 [链接]()
## 全局常量                    ← 表格：常量 | 值 | 作用域
## 初始化顺序                  ← 表格：步骤 | 操作 | 关键代码 | 备注
## 数据路径                    ← 表格：路径A vs 路径B + 注意
## 信号总览                    ← 表格：发射者 | 信号签名 | 接收者 | 槽函数 | 作用
## 术语映射                    ← 表格：用户用语 | 代码/内部术语 | 所在文件
## 操作步骤清单                ← ### 子标题，编号步骤
## 决策记录                    ← **DR-xxx**：标题 + 原因 + 位置 + 状态
## 项目级禁止清单              ← **R-001** ~ **R-008**，每项一段
## 文件详情                    ← 表格：文件 | 文档（链接到 .py.md）
```

### 各章节格式细节

**索引**：无围栏代码块（确保链接可点击）。树节点用 `├──` `│   ` `└──`。

**全局常量**：
```markdown
| 常量 | 值 | 作用域 |
|---|---|---|
| `DATA_DIR` | `../data` | JSON 数据目录 |
| `DDL_CRITICAL` | ≤3 天 | task_panel.py 红色阈值 |
```

**初始化顺序**：
```markdown
| 步骤 | 操作 | 关键代码 | 备注 |
|------|------|----------|------|
| 1 | 单实例检测 | `QLocalSocket.connectToServer` | 若连接成功则退出 |
```

**数据路径**：
```markdown
| | 路径 A (UI 操作) | 路径 B (AI / TG 操作) |
|---|---|---|
| 入口 | Panel → DataManager | AI → actions.py |
| 通知 | DataManager emit data_changed | 3s轮询 mtime → >0.1s → emit |
```

**信号总览**：
```markdown
| 发射者 | 信号签名 | 接收者 | 槽函数 | 作用 |
|---|---|---|---|---|
| `DataManager` | `data_changed(str)` | GitSync | `on_data_changed` | 触发同步（参数固定为 `"external"`） |
```

**术语映射**：
```markdown
| 用户用语 | 代码/内部术语 | 所在文件 |
|---|---|---|
| 作业 | TaskPanel / TaskModel | `task_panel.py` / `tasks.json` |
```

**操作步骤清单**：每个操作用 `###` 标题，编号步骤。

**决策记录**：
```markdown
**DR-xxx：标题**
- **原因**：为什么
- **位置**：代码位置
- **状态**：锁定 / 待确认
```

**项目级禁止清单**：
```markdown
**R-001：标题**
规则描述。禁止事项。后果说明。
```

**文件详情**：
```markdown
| 文件 | 文档 |
|---|---|
| `app.py` | [src/app.py.md](src/app.py.md) ✅ — 应用入口 |
| `data_manager.py` | [src/services/data_manager.py.md](src/services/data_manager.py.md) ✅ — 数据枢纽 |
| `main_window.py` | *（待补）* |
```

## 二、逐文件格式（.py.md）

### 目录镜像规则

源码 `src/services/ai_service.py` → 文档 `MD-files/src/services/ai_service.py.md`

### 必需章节（按顺序）

```markdown
### <文件名>

**职责**：一句话
**架构层级**：Application / Service / Model / UI Layer
**运行环境**：平台 + 关键依赖
**继承**：（若继承非默认类，如 QObject、BaseJsonModel）
**设计要点**：（可选，复杂文件加）

---

#### 跨文件引用矩阵
| 本文件引用 | 被引用文件 | 引用类型 | 用途 |
（仅列项目内引用；标准库和 PySide6 不进此表；动态导入标"动态 import"）

#### 文件级常量 / 约定
| 常量/约定 | 值 | 说明 |
（不仅限传统常量——.tmp后缀、重试次数、间隔时间、键名约定都列进来）
（如全无，写"（无）"而非省略整个表）

#### 类实例变量
| 变量 | 类型 | 作用 |
（多类文件按类名分组：**AIService** | | 然后列变量）

#### 信号（如有）
| 信号 | 签名 | 触发时机 | 携带数据 |
（多类文件按类名分组；互斥信号在表后加 > 引用块说明）

#### 函数合同

##### `<函数名>(<参数签名>) → <返回类型>`
- **前置条件**：
- **核心逻辑**：（≤5 步，用源码变量名）
- **副作用**：
- **返回值**：
- **异常行为**：（不写"无"——写"无显式处理，XX 情况会向上传播 XXError"）
- **信号来源**：（若为槽函数）

##### `<属性名>`（属性 getter/setter）
- **getter**：返回 `self._xxx`
- **setter**：设置 `self._xxx = value`
- **副作用**：setter 不自动保存

函数顺序必须与源码一致。

#### 禁止做的事
- **禁止 XX**（引用 R-xxx）：规则描述
（先引用全局规则，再列文件特有禁止项）

#### 操作步骤清单
##### 操作名称
1. 步骤

#### 术语映射
| 用户用语 | 代码/内部术语 | 所在位置 |
（不重复全局已有机术语）

#### 决策记录
**DR-XX-xxx：标题**
- **原因**：
- **位置**：
- **状态**：锁定 / 待确认

（同步到 AllTheFiles.md 时只写一行引用 + 关键字）

#### 待办（若有）
> **待办**
> 1. 问题。待做什么。
```

### 合同字段使用规则

| 字段 | 何时必有 | 何时省略 |
|---|---|---|
| 前置条件 | 有外部依赖、调用顺序要求时 | `__init__` 简单赋值时写"无" |
| 核心逻辑 | 始终 | — |
| 副作用 | 有 emit/写文件/改 self 时 | 纯计算/只读 |
| 返回值 | 始终（`→ None` 也要写） | — |
| 异常行为 | 始终（有处理写处理，无处理写传播路径） | — |
| 信号来源 | 槽函数 | 非槽函数省略整行 |

## 三、分层适配

| 层级 | 信号 | 常量表 | 特殊关注 |
|---|---|---|---|
| Application | 多，含内部 | 有 | 初始化顺序、单例锁 |
| Service | 有（QObject） | 少/约定 | 线程安全、动态导入 |
| Model | 无 | 约定为主 | 原子写入、版本迁移、属性 |
| UI | 有（QWidget） | 少 | QSS 约束、信号连接、禁止清单 |
| Script | 无 | 有 | CLI 接口契约 |

## 四、写完同步清单

每个 .py.md 完成后，必须检查 AllTheFiles.md 是否需要更新：

- [ ] 文件详情表：`*（待补）*` → 链接 + ✅
- [ ] 文件树：加 `✓`
- [ ] 信号总览：有新信号？
- [ ] 术语映射：有新术语？
- [ ] 决策记录：加一行 DR-xxx 引用
- [ ] 操作步骤清单：有新操作？
- [ ] 禁止清单 R-xxx：有新硬编码需要扩展？
