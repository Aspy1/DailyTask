# 接口文档

## 数据操作脚本 (scripts/actions.py)

AI 和 TG bot 统一通过此脚本操作数据，不直接写 JSON。

```sh
python scripts/actions.py <动作> [--参数 值 ...]
```

### 作业

```sh
# 添加 (课程名支持模糊匹配, 日期支持中文相对表达)
python scripts/actions.py add_task --course "算法课" --title "01背包" --due "下周日"
python scripts/actions.py add_task --course "计算机网络" --title "第四章" --due "2026-06-14" --priority high
# 标记完成
python scripts/actions.py complete_task --id "t_001"
```

### 考试

```sh
python scripts/actions.py add_exam --course "高等数学" --date "2026-06-20" --scope "第1-8章" --location "教学楼A201"
```

### 习惯

```sh
python scripts/actions.py add_habit --name "跑步" --schedule "daily/1" --duration 30 --reminder "20:00"
python scripts/actions.py add_habit --name "健身" --schedule "weekly/1,3,5" --duration 60
python scripts/actions.py log_habit --id "h_001"
```

### 课程

```sh
python scripts/actions.py add_course --name "高等数学" --day 1 --weeks "1-16" --slots "1-2" --location "A201" --teacher "张老师"
python scripts/actions.py delete_course --id "c_001"
```

### 日程计划

```sh
python scripts/actions.py add_plan --date "2026-06-08" --title "复习算法" --slot 3
python scripts/actions.py replace_plans --date "2026-06-08" --plans '[{"title":"复习","time_slot":3},{"title":"写作业","time_slot":5}]'
python scripts/actions.py delete_plan --date "2026-06-08" --index 0
```

### 查询

```sh
python scripts/actions.py status   # tasks/habits/courses/exams 统计
```

### 模糊匹配

- 课程名：`"算法课"` → 匹配 `"算法设计与分析"`, `"毛概"` → 匹配 `"毛泽东思想和中国特色社会主义理论体系概论"`
- 日期：`"下周日"` `"6月20日"` `"明天"` `"3天后"` `"6.20"`
- 时段：1=08:30-10:05, 2=10:25-12:00, 3=13:30-15:05, 4=15:25-17:00, 5=18:30-20:05, 6=20:10-21:45

## 数据模型 API

### TaskModel (tasks.json)

| 方法 | 说明 |
|------|------|
| `add(task) → str` | 新增，自动生成唯一 ID |
| `complete(id) / uncomplete(id)` | 状态切换 |
| `pending / completed → list` | 按状态获取 |
| `active → list` | 全部活跃 (含已完成) |

### ExamModel (exams.json)

| 方法 | 说明 |
|------|------|
| `add_exam(data) → str` | 新增考试 |
| `update_exam(id, data) → bool` | 更新 |
| `delete_exam(id) → bool` | 删除 |
| `get_upcoming(limit) → list` | 未来考试 |
| `exams → list` | 全部考试 |

### HabitModel (habits.json)

| 方法 | 说明 |
|------|------|
| `add_habit(habit) → str` | 新增 |
| `log(id, completed) → list` | 打卡 (返回附加事项) |
| `is_active_today(id) → bool` | 今日是否激活 |
| `postpone(id, until) / cancel_today(id)` | 推迟/取消 |

### AI 指令流程

1. 用户输入 → AI 理解意图 + 标准化参数
2. AI 回复自然语言确认 + ````sh` 代码块
3. InstructionParser 提取命令 → subprocess 执行 actions.py
4. actions.py 验证参数、模糊匹配、生成 ID、写 JSON
5. DataManager 3s 自动 reload → UI 刷新

## 信号

| 信号 | 触发 |
|------|------|
| `data_changed.emit(action)` | 数据变更 |
| `ddl_alert.emit(count)` | DDL 紧急计数 |
| `reminder_notify.emit(title, msg)` | 托盘提醒 |
| `arrange_requested.emit(prompt)` | 日程调整请求 |
