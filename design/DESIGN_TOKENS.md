# 生活助手 — 设计标准规范

> 版本 2.0 | 令牌**单一真值**是 `src/ui/styles/tokens.json`
> 标注"（生成）"的表格由 `scripts/gen_design_tokens.py` 产出，**请勿手改**——改令牌请改 `tokens.json`。

---

## 设计哲学

**暖纸书房 (Warm Paper Study)** — 浅色模式为主。像一本精心排版的纸质日程本：米白底、深炭字、克制暖金点缀。不冷、不刺眼、不"科技感"。

核心原则：
- **内容优先**：装饰服务于信息，不抢信息
- **克制配色**：1 主色 + 1 点缀色 + 灰阶，禁止第四种色相
- **呼吸留白**：数据密集但视觉不拥挤，留白面积 ≥ 40%
- **零 AI 俗套**：禁止紫粉渐变、emoji 图标、左侧彩色边框卡片、Inter/Roboto 字体

### 1.3 配色硬规则

- **禁止第四种色相**。只有暖灰 + 琥珀金 + 功能色(红/绿)
- **禁止组件中硬编码 hex**。一律走 `get_colors()` 取 token
- **禁止纯黑 `#000` 和纯白 `#FFF`**
- **accent 使用率 < 5% 像素面积**：强调色是"标点符号"，不是"背景色"

### 2.3 字重使用规则

| 字重 | 何时使用 |
|------|---------|
| **300 (Light)** | 仅大标题 36px+，营造呼吸感 |
| **400 (Regular)** | 正文、表格、标签、输入框、菜单——默认字重 |
| **500 (Medium)** | 卡片标题、导航选中项、按钮文字、重点数字 |
| **600 (SemiBold)** | 区块标题、对话框标题——"需要明显层级跳升"时才用 |
| **700 (Bold)** | 不使用。中文下 600→700 视觉差异极小，统一用 600 |

### 2.4 粗体使用判断

问自己：**这个元素需要比周围文字"跳"一级吗？**
- 跳一级（细微强调）→ 500 (Medium)
- 跳两级（明显分层）→ 600 (SemiBold)
- 不需要跳 → 400 (Regular)

### 2.5 禁止

- 正文 < 13px（表格 12px 是唯一例外）
- 中文斜体（可读性差）
- 全大写英文标题（中文 UI 中不协调）

### 2.6 CJK 小字号规则

12px 及以下中文仅允许在**有明确视觉容器**的场景使用：

| 允许 | 不允许 |
|------|--------|
| 表格行（有交替底色 + 行高光） | 纯白底上的长文本 |
| 状态栏（有底部色条） | 卡片正文 |
| Tag 标签（有色块背景，≤4 字） | 段落文字 |
| 表头（有 bg_surface 背景） | 无背景的孤立标签 |

原因：中文字笔画密度高（"课程"=25 画），小字号下 ClearType 无法解析细节。视觉容器（色块/行色）提供锚点，人眼靠上下文补全模糊笔画。

## 三、间距体系

### 3.1 基础网格：4px

所有间距从以下值选取，不用中间值：

```
4, 8, 12, 16, 24, 32, 48, 64
```

### 3.2 场景对照

| 值 | 使用场景 |
|----|---------|
| 4px | 图标-文字间距、标签内边距、紧密相关元素 |
| 8px | 卡片内边距、按钮上下内边距、列表项间距 |
| 12px | 按钮左右内边距、输入框内边距、表头内边距 |
| 16px | 面板外边距、卡片间距、段落间距 |
| 24px | 区块间距、对话框内边距 |
| 32px | 标题-内容间距 |
| 48px | 大区块分隔 |
| 64px | 页面级大分隔 |

### 3.3 导航栏

- 高度：**52px**（原 50px→52px 修复挡字）
- 上下 padding：8px
- 按钮间距：4px
- 左侧 padding：16px

## 四、圆角体系

| 尺寸 | 适用元素 |
|------|---------|
| **4px** | 小按钮、标签、徽章、复选框、输入框 |
| **8px** | 卡片、面板、对话框、下拉菜单、普通按钮 |
| **12px** | 弹窗、模态框 |

### 规则

- **同类元素同圆角**。不能 Card A 是 6px，Card B 是 10px
- **最大 12px**。超过会"软糖感"
- **表格、分割线、状态栏用直角**。功能区域不圆角

## 五、按钮与交互状态

### 5.1 按钮层级

| 层级 | 样式 | 每页上限 |
|------|------|---------|
| **主按钮** | `accent` 填充 + `#fff` 文字 | 最多 1 个 |
| **次按钮** | 透明 + `border` 边框 + `fg_primary` 文字 | 不限 |
| **文字按钮** | 完全透明 + `accent` 文字 | 不限 |
| **危险按钮** | `red` 填充 + `#fff` 文字 | 仅确认态 |

### 5.2 按钮四态

每个按钮必须覆盖默认/悬停/按下/禁用：

| 状态 | 主按钮 | 次按钮 | 文字按钮 |
|------|--------|--------|---------|
| **默认** | `bg: accent, fg: #fff` | `bg: transparent, border, fg: fg_primary` | `bg: transparent, fg: accent` |
| **悬停** | `bg: accent_hover` | `bg: rgba(0,0,0,0.04)` | `fg: accent_hover` |
| **按下** | `bg: accent_dim` | `bg: rgba(0,0,0,0.08)` | `fg: accent_dim` |
| **禁用** | `bg: fg_disabled, fg: #fff` | `fg: fg_disabled, border: divider` | `fg: fg_disabled` |

### 5.3 交互细节

- **过渡**：150ms ease-out
- **最小高度**：32px
- **可点击区域**：≥ 32×32px（含内边距）
- **复选框区域**：≥ 28×28px

## 六、渐变

### 原则：几乎不用

渐变是 AI 生成 UI 的头号识别特征。

- **禁止**：按钮渐变、卡片渐变背景、导航栏渐变
- **禁止**：紫粉蓝多色渐变
- **仅允许**：空状态插图微妙的径向光晕（单色，< 8% 不透明度）

---

## 七、阴影与层级

### 浅色模式阴影

| Elevation | 阴影 | 使用场景 |
|-----------|------|---------|
| **0** | 无 | 根背景、表格、列表 |
| **1** | `0 1px 3px rgba(0,0,0,0.04)` | 卡片 |
| **2** | `0 2px 8px rgba(0,0,0,0.06)` | 下拉菜单、弹出面板 |
| **3** | `0 4px 16px rgba(0,0,0,0.08)` | 模态框、对话框 |

- QSS 对 box-shadow 支持有限，主要靠**背景色深浅 + 边框**实现层级

## 八、图标

- **禁止 emoji 作 UI 图标**。状态栏 `⏎` 改为纯文本符号
- 过渡期用系统字符：▶ ▼ ▲ ● ○ ◇ □ ★ → ←

## 九、动效

| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮悬停/按下 | 150ms | ease-out |
| 面板切换 | 200ms | ease-out |
| 对话框打开/关闭 | 200ms | ease-out |
| 通知出现 | 250ms | ease-out |

- 禁止弹跳、弹性、旋转等装饰动效
- 禁止 > 300ms 的动画——这是工具不是表演

## 十、代码规范

```python
# ✅ 颜色：走 token
c = get_colors()
btn.setStyleSheet(f"background-color: {c['accent']}; color: #fff;")

# ❌ 禁止硬编码 hex
btn.setStyleSheet("background-color: #B0823A;")

# ✅ 间距：用标准值
layout.setContentsMargins(16, 12, 16, 12)

# ✅ 字体：用主题变量
label.setFont(QFont(FONT_CN, SIZE_TITLE))
```

### 修改流程

1. 改 `src/ui/styles/tokens.json`（**唯一真值**；用途注释写进 `color_notes`）
2. `.venv\Scripts\python.exe scripts/gen_design_tokens.py` 重新生成本文档的令牌表
3. 若涉及新的语义，再改 `theme.py` 的 QSS 生成
4. 逐面板替换硬编码颜色（禁止 `#hex`，见 `CODE_STANDARDS Q-H1`）
5. `.venv\Scripts\python.exe main.py` 验证 → commit
