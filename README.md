# 生活助手

AI 驱动的桌面日程管理应用，帮助管理课程、作业、习惯、记账和余额。

## 技术栈

- **UI**: PySide6（Qt for Python）
- **AI**: DeepSeek / Claude API，自然语言控制所有数据
- **数据**: JSON 本地存储（原子写入 + 重试）
- **定时**: GitHub Actions 每日邮件摘要 + 本机托盘提醒

## 主要功能

### 学习
- **日程视图**（默认首页）：按时段展示课程、自定义计划、习惯，左侧 ▶ 箭头指示当前时间
- **课程表**：从日程顶部按钮打开，纯查看模式。支持多时段（默认 5 节/天）、周段解析、教师轮换
- **作业**：表格视图，按课程/时间筛选，复选框标记完成，自动归档

### 生活
- **生活习惯**：卡片网格布局，支持每周固定日（周一三五）或每隔 N 天；附加事项自动生成待办；右键推迟/取消；完成即记录
- **记账**：分类支出记录、月度预算、今日/本月/预算剩余三卡片
- **存钱助手**：记录每日省钱金额
- **余额提醒**：校园卡 / 水卡 / 电费余额追踪，低于阈值弹窗 + 邮件

### AI 助手
- 自然语言输入，支持的操作：
  - 课程：添加、修改、删除、批量导入
  - 作业：添加、完成、关联课程
  - 习惯：添加、修改、删除、推迟、取消今日；识别 "我习惯..." 触发词
  - 记账：记录支出（自动识别校园卡/水卡支付并扣减余额）、修改、删除、设置预算
  - 存钱：记录、删除
  - 余额：查询、更新
  - 日程计划：添加、删除
- 聊天气泡样式 + Markdown 渲染
- 上下文自动压缩，防止 token 溢出

### 邮件提醒
- **GitHub Actions**（每日 04:55 北京时间）：摘要包含课程、计划、习惯、DDL、考试、余额
- **本机**：DDL 6 小时内邮件、考试 14/7/3 天邮件、习惯提前 5 分钟托盘弹窗

### 其他
- 系统托盘图标、开机自启动（Windows 注册表）
- 单实例锁（QLocalServer）
- 深色 / 浅色主题切换
- "天"按上课划分（凌晨 0-1 点算昨天）
- 数据自动同步到 GitHub（30 秒防抖 + 手动同步按钮）
- 自定义应用图标

## 运行

```bash
pip install -r requirements.txt
python main.py
```
